# REIT Data Requirements (for panel build)

## Required

You need one **REIT-level source dataset** (monthly or higher frequency) with at least:

- `reit_id` (or `ticker`): REIT entity identifier
- `date`: observation date
- at least one numeric REIT variable (for example: `price`, `return`, `market_cap`)

Target after processing:

- Entity = REIT
- Time = Month
- At least 120 months in range

## Optional but recommended

Add monthly supplementary datasets such as:

- FRED macro indicators (e.g., CPI, Fed Funds, 10Y Treasury)
- Housing market data (e.g., starts, permits)
- Labor market data (e.g., unemployment, payrolls)

These merge on `month` (or on `reit_id` + `month` if entity-specific).

## Run example

```bash
python code/build_reit_panel.py \
  --source data/raw/reit_master.csv \
  --entity-col reit_id \
  --date-col date \
  --supplementary data/raw/fred_monthly.csv data/raw/housing_monthly.csv
```

## Notes on missing values

Document your rule in metadata (already auto-generated by script), for example:

- leave missing as-is, or
- use `--fill-forward-numeric` to fill within each REIT.
